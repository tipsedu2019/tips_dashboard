- 상담 신청/완료·대기·청강·등록 신청·완료의 desktop 열은 같은 CSS subgrid 행을 공유한다. 긴 책임자·수업·교재·시간 문자열이 한 과목의 높이를 늘리면 다른 열의 같은 과목도 함께 늘어난다. 값이 없는 트랙도 `미정`/`미지정` 공간을 남긴다. 상태 열의 과목을 기준으로1회 보이며 다른 열의 과목은 screen-reader 문맥으로 보존한다.
