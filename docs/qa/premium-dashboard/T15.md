# T15 — 수업일정 진도와 다음 작업

2026-09-15, internal-dashboard-only worktree. UI 표현만 변경했으며 API/상태/정렬/필터/그룹/저장 계약은 유지한다.

- 현재 numbered RPC의 exact-key row는 id/name/subject/grade/schedule/status 및 nullable 식별 메타만 반환한다. 계획 sessions, billingPeriods, progress는 없다. 목록 어댑터가 생성하는0은 실제 조회된0이 아니다. 상세 조회 결과는 편집용 selectedRow에만 합쳐지며 목록 모델에는 합쳐지지 않는다.
- 따라서 실제 목록의 누락 진도는 `진도 미조회`, 회차/다음 작업은 상세 확인으로 표시한다. 누락값을 정상으로 간주하던 배지와 가짜 전체 회차 합계도 제거한다. 상세 열기·수업 설계·홈페이지 링크는 보존한다.
- 순수 formatter는 수락된 계획0/실제0이면 `계획 없음`,5/10이면 `5/10회·50%`.0분모 양수 실제값은 계획 확인 필요이며 비율은 표시하지 않는다. 미조회/로딩/오류/권한/기간 없음은 서로 다른 상태다.
- 실제 다음 회차가 있을 때만 기록 메타 배지를 표시한다. 정상은 중성 텍스트로 낮추고 경고에는 아이콘과 텍스트를 유지한다. 수업 설계는 보조 outline 버튼이다.
- 현재 exact numbered contract로는 양수 진도와 수락된 빈 계획을 목록 fixture에 주입할 수 없다. helper 테스트는 이 표현 계약의 증거이며 실제 transport 또는 DB 진도 검증이 아니다. API 확장은 이 카드 범위 밖이다.

검증: 새 formatter3건 포함 관련 class-schedule draft/content/generation, continuous-service/consumer-parity, curriculum-filter tests55건 통과. 영향 source ESLint 통과. 브라우저 경로 증거는 T20 잔여 경로 manifest에 함께 기록한다. 운영 데이터 변경·provider 발송·배포 없음.
