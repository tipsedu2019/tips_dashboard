## 변경 시 유지한 경계

- 입학 알림톡은 저장된 유효 수업 정보를 기준으로 미리보기를 준비한다. 특정 수동 진행상태를 먼저 선택하도록 강제하지 않는다. 보관·검토 필요·중복·부정확한 수업 정보 및 권한 검사는 유지한다.
- 새 과목팀 알림은 기존 이벤트·규칙·발송 소유권·중복 방지 경로를 사용한다. 실제 과목과 수신 방을 계획·재검증·외부 발송 직전 단계에서 대조한다.
- 등록 진행상태 변경과 재시험 점수·통과 기준이 바뀐 후에는 오래된 과목팀 알림을 차단한다.
- 등록 상태 저장 뒤 과목팀 알림 요청·본문 수신은 20초로 제한한다. 지연 시 재발송하지 않으며, 저장 완료와 알림 결과 확인 필요를 구분해 표시한다.
- 자동 할 일 정리는 자동 생성 연결 또는 규칙 실행 기록이 있는 일반 할 일로 한정한다. 완료 이력과 수동 할 일을 지우지 않는다.

## 검증 기록

- 합성 데이터로 실제 페이지를 렌더링해 PC 1365px·모바일 390px에서 일정 충돌 목록·상세·기간 변경·오류 후 재조회·빈 상태를 확인했다. 할 일 생성 API 호출은 없었다.
- 같은 환경에서 입학 알림톡 버튼과 학생·수업 정보가 들어간 미리보기, 확인 후 발송 버튼, 체크박스와 발송의 독립성을 확인했다. 실제 발송은 누르지 않았으며 외부 제공자 호출은 0건이었다.
- 변경된 테스트 파일을 묶어 실행한 회귀 검증은 768개 모두 통과했다. 이후 설정 미리보기 예시 수정은 관련 41개 테스트와 빌드로 다시 확인했다. 마이그레이션 레이아웃 검증 40개도 통과했다.
- 발송 방지 환경에서 192개 메시지 조합을 렌더링하고, 폐지된 10개 Chat 조합을 차단했다. 유효한 56개 Chat 조합의 가짜 전송 내용이 일치했으며 실제 외부 요청·운영 발송 시도 행은 0건이었다.
- 실제 격리 DB에서 기본 스키마 검증 1,937개와 업무 pgTAP 9개 파일·241개 검증이 통과했다. 신규 과목팀 알림 39개, 입학 미리보기 21개, 자동 할 일 정리 26개 검증을 포함한다.
