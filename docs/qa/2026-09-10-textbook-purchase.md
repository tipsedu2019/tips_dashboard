# 요청·주문·입고 목록 정돈 · 2026-09-10

## 범위와 변경

교재관리 단순화 다음 단계로 요청·주문·입고의 공통 처리표를 정돈했다. 교재명보다 처리일시·요청자가 먼저 나오고, 학생용·교사용 수량이 여섯 열로 분산되며, 모든 행 작업이 나란히 표시되던 구성을 개선했다.

- 교재명을 첫 번째 정보 열로 옮기고 긴 이름은 데스크톱과 모바일에서 줄바꿈한다.
- 주문·입고의 수량을 요청/주문/입고 세 열로 묶는다. 각 열 안에 학생용·교사용 숫자를 각각 표시하며 0과 알 수 없는 집계도 구분한다. 요청 탭에는 요청 한 열만 표시한다.
- 집계는 기존 서버 summary를 그대로 사용한다. 페이지에 보이는 행을 합산해 전체 합계로 대신하지 않는다. 중복 전체 요약 줄만 제거하고 그룹 요약·합계·페이지 건수는 유지한다.
- 행의 기본 버튼은 다음 단계인 주문/입고 또는 미등록 교재 등록으로 정한다. 수정·반품·삭제·외부 교재 검색은 더보기 메뉴에 배치한다. 요청 탭의 기본 수정 버튼은 유지한다.
- 공급처별 주문서와 반품 요청서를 하나의 주문서 메뉴로 묶고 기존 전체 대상 조회와 문서 생성 함수를 호출한다.
- 주문 표의 최소 너비는 1440→1280px, 요청 표는 1120→1040px, 작업 열은 132px로 줄였다. 부가 열은 내부 가로 스크롤과 기존 컬럼 구성으로 접근한다. 스크롤 영역이 직접 키보드 초점을 받고 내부 Table 컨테이너는 별도 스크롤을 만들지 않는다.
- 연결 수업의 준비된 `studentCount`를 표시 판단에 사용한다. 학생 전체 배열이 없는 페이지에서 연결된 수업이 ‘수업 미선택’으로 나오던 오류를 수정했다.
