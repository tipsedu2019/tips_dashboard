# 시간표 편성 간소화 검증

기준: 기존 `/admin/timetable`의 `WorkspaceTabs`, `DataTableFilterPanel`, 공용 Select/Dialog/Button. 전역 스타일 변경 없음. 원장 운영자 역할은 `admin`; 일반 선생님, 관리팀, 조교의 기존 운영 메뉴 권한은 유지한다.

## 변경
- 영어·수학 편성 및 과목별 선생님 필터. 조교팀·관리팀·과학팀을 프리셋 선생님 패널/열/선택지에서 제외한다. 서버의 전체 충돌 참조 자료는 유지한다.
- 프리셋 이름만 입력한다. 기간·보관함·기존 초안 가져오기·보관·공유 진입점 제거. 이름 변경·복제 및 기존 요청의 안전한 재시도 유지.
- 프리셋 조회, 행 RLS, 실시간 신호, 수정, 반영 RPC를 admin으로 제한. 과거 공유 멤버십은 접근 권한이 되지 않는다.
- 선택 수업을 운영의 개강 준비(기본값) 또는 수강으로 복사·이동. 상태도 미리보기/확정/재시도 요청에 포함한다. 종강은 시간표 필터에서 제외하고 기존 기록은 보존한다.
- 운영에 반영한 개강 준비 수업은 전송 기록의 `selected_mapping`으로 식별하여 충돌 참조에 포함한다. 수업 관리의 기존 개강 준비 초안은 바꾸지 않는다. 원본 프리셋을 이동하여 제거해도 예약 시간은 유지된다.

## 검증
- 130개 순차 마이그레이션을 외부 네트워크가 없는 임시 PostgreSQL에 재생.
- 시간표 pgTAP 829개 assertion 통과. 원장/기존 공유 선생님/관리팀/조교/RLS/익명 접근, copy/move × 1/3/전체 선택, 새 상태와 미리보기 바인딩, 중복 확정, 실제 SQLSTATE `42501`, `P0001`, `23P01`, 기존 이력·알림 무변경 포함.
- 시간표·공용 디자인 Node 182개 통과. TypeScript 및 변경 파일 ESLint 통과.
- 실제 Next 앱 + 임시 DB RPC로 수업 선택 → 개강 준비 복사 → 반영 완료 → 일반 선생님으로 재접속 → 개강 준비 수업 조회 확인. 분 단위 17:13–18:13 보존.
- 영어 필터의 선생님 선택지와 일별 선생님 열 연동, 더보기의 이름 변경/복제만 노출, 종강 옵션 제거, 일반 선생님의 프리셋 진입점 부재 확인.
- 390×844 모바일에서 선생님의 개강 준비 조회 화면 확인 (`teacher-mobile.png`, `director-mobile.png`). 프리셋 이름 입력 대화상자는 `preset-name.png`에 기록했다.

운영 데이터 사전 확인: 보관된 프리셋 0개, 기간이 지정된 프리셋 0개. 운영 데이터의 수업/수강생/출결/수납은 검증용으로 변경하지 않는다. 실제 직원에게 확인 요청 메시지를 발송하는 기능은 이번 변경에 포함하지 않는다.
