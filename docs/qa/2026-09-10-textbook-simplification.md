# 교재관리 기능 단순화 검수 · 2026-09-10

## 요청과 판단

사용자가 교재관리의 복잡함을 지적하고 불필요한 기능을 제거하도록 요청했다. 이번 범위는 기존 마스터 목록을 다시 꾸미는 것이 아니라, 실제로 다음 행동을 돕지 않는 메뉴와 상태 표시를 줄이는 것이다.

- 기존 ‘할 일’은 미등록 요청·주문·부분입고·출고·재고 부족의 합산 메뉴였다. 별도 업무가 아니라 기존 탭과 조건으로 이동하는 중복 진입점이었고 합계가 독립된 업무 수를 보장하지 않았다.
- 재고 상태의 부족·과잉은 실제 수요나 발주 기준 없이 3권 이하/20권 이상이라는 수량 기준을 사용했다. 목록에는 실제 위치별 수량을 남기고 휴리스틱 필터와 적은 양의 양수 재고에 대한 경고색을 제거했다. 음수 재고의 오류 구분은 유지한다.
- 정리 상태는 선택 정보인 ISBN·바코드 누락까지 경고로 만들었다. 상태 필터와 교재별·과목 그룹별 정리 배지를 제거했다. 신규·수정 시 중복 확인, 분류 입력 검증, 재고 부족으로 인한 실제 출고 제한은 유지한다.

## 구현

- 검색, 과목·세부과목·학교 구분·학년의 네 가지 분류 필터, 신규 등록을 기본 목록 조작으로 유지했다.
- 미사용 교재는 한 번 눌러 전환하고 다시 눌러 돌아오는 토글로 분리했다. 상태는 `aria-pressed`로 전달한다. 기존 미사용 교재 복구·삭제 절차와 재확인은 그대로 둔다.
- 마스터 탭은 ‘교재 목록’, 재고 탭은 ‘재고 실사’로 바꿨다. 요청·주문·출고에만 처리할 건수를 남겼다.
- 전체 탭에서 중복 상태 배지 줄을 제거하고 공통 새로고침 버튼을 업무 탭 옆 한 곳에 두었다.
- 재고 실사의 실제 실사 작업 분류는 유지하고 ‘할 일’이라는 표기를 ‘실사 권장’으로 명확히 했다. 실사 권장 계산 규칙은 이번 변경 대상이 아니다.
- 이전 URL에 남은 정리·재고 필터는 첫 조회 전에 해제하고 1페이지로 복원한다. 검색·분류·페이지 크기·독립 이력·상세·무관한 URL 값은 보존한다. 명시된 미사용 목록은 유지한다.
- 재고 실사 조회는 항상 사용 중인 교재를 대상으로 한다. 실사 위치·작업 범위의 로컬 필드가 공통 필터 URL에 섞여 다음 복원 시 분류가 유실되는 문제도 막았다.

## 실제 브라우저

별도 검수 탭에서 실제 제품 컴포넌트와 엄격한 조회 서비스를 합성 데이터 응답에 연결했다. 사용자가 열어 둔 편집 탭은 검수 조작 대상으로 사용하지 않았다.

- 데스크톱 1280×720: 분류 필터 4개, 새로고침 1개, 폐기 컨트롤 0개, 현재 페이지 교재 10행. 문서 가로 너비 1280px로 넘침 없음.
- 모바일 390×844: 두 열 분류 필터와 교재 카드, 긴 교재명 줄바꿈, 검색 결과 없음, Escape 초기화 확인. 문서 너비 375px로 가로 넘침 없음. 임시 viewport는 원복했다.
- 사용 중 23종과 미사용 1종 사이 토글, 검색 복귀, 요청·주문·출고·실사·정산 탭 진입을 확인했다.
- 기존 missingCode/shortage, 영어 분류, 3페이지, 15개씩 보기 URL을 열었을 때 영어 분류·15개씩 보기는 유지하고 폐기 조건을 해제해 1페이지 11종을 표시했다.
- 방향키는 요청 탭으로 포커스만 옮기며 선택된 교재 목록은 유지한다. 자동 테스트에서도 활성화 전 RPC가 실행되지 않는 것을 확인했다.
- 최초 로딩의 tabpanel/비활성 새로고침, 합성 조회 오류의 재시도·알 수 없는 건수 표시를 확인했다.
- 최종 정상 재진입 이후 콘솔 오류 0. 편집 중 임시 helper 누락은 수정했으며, fixture의 빈 출고 이력 집계 응답 형식도 계약에 맞게 보정 후 재검수했다.

## 증거와 범위

브라우저 viewport 측정은 DOM 기준이며 캡처 파일은 도구 출력 크기(최종 desktop 1280×720, mobile 375×812)를 유지한다. 변경 전 캡처는 1265×712이므로 동일 픽셀 크기 비교 자료로 주장하지 않는다.

이미지·최종 DOM 측정·검사 로그는 `.codex-artifacts/textbook-simplification-20260910/`에 있다. `before-workspace.tsx`와 `before-navigation.ts`는 이번 요청 시작 시점의 기준 코드다. 본 검수는 로컬 합성 데이터 검수이며, 실서비스 데이터 변경·실재고 이동·외부 주문 전송·배포를 수행하지 않았다. 데이터 구조, RPC 계약, DB migration은 변경하지 않았다. 전용 주문·출고·실사·정산 화면 전체의 별도 리디자인 완료를 의미하지 않는다.
