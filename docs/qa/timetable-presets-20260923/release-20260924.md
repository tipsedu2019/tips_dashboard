## PR CI 후속 수정

첫 PR CI에서 수업관리의 일정 stale 오류가 한국어로 변환된 뒤 기존 오류 코드 문자열 검사에서 누락되어 최신값 복구 버튼이 사라지는 회귀를 발견했다. 원본 오류의 message를 판별하도록 수정했고, 기존 race/continuous/progressive UI 검사 110/110, TypeScript, 변경 파일 lint가 통과했다.

기존 SQL 다섯 파일은 과거 중복·불완전 시간표를 fixture로 만들므로, fixture 준비 직후 owner 권한으로 해당 트랜잭션의 운영 점유 기준을 고정하도록 정리했다. 테스트 대상 RPC를 호출하기 전 모든 constraint를 다시 immediate로 돌리며, 제품의 함수·트리거·권한과 충돌 assertion은 변경하지 않았다. 로컬 재검사에서 numbered 134, statistics 55, observation status 27, booking 47개가 통과했다. archived delivery는 기존 실패 지점을 넘어 41개 통과 뒤 이 PostgreSQL-only 컨테이너의 dblink TCP 접속 제한에서 멈췄다. 전체 결과는 Supabase CLI 환경의 PR CI 재실행으로 확인한다.
