# 교재관리 등록·편집 폼 통일 · 2026-09-10

18단계에 이어 요청·주문·입고·출고의 입력 창 배치, 저장·취소, 실패 처리를 정리했다. 별도 작업 브랜치 `codex/dashboard-apple-design-20260909`의 로컬 구현이다.

## 적용

- 공통 `ui/form-dialog.tsx`의 `FormDialogContent`를 요청/주문/입고, 일괄 주문, 출고에 적용했다. 기존 Dialog, Button, Alert를 조합한다. 제목과 하단 행동은 고정하고 본문만 스크롤한다. 데스크톱은 최대 42rem 높이, 모바일은 화면 가장자리 1rem 여백을 유지한다.
- 주문·입고의 최소 너비를 강제하던 3열을 제거했다. 교재는 전체 너비, 선생님·위치는 한 쌍, 학생용·교사용 수량은 같은 행에 배치한다. 계산된 참고 값은 수량 입력 아래로 옮겼고 모든 값은 보존했다. 모바일은 한 열로 배치한다.
- 취소/저장 위치와 상태를 공통화했다. 저장 중 버튼 이름·너비를 유지하고 같은 크기의 진행 아이콘과 상태 안내를 사용한다. 입력 방식/출고 대상은 기존 공통 Button을 사용한다. 편집 창 안의 중복 ‘새 요청/새 주문’은 목록의 기존 추가 동선으로 통합했다.
- 비활성 저장 이유를 화면 안에 표시한다. 저장 실패는 해당 폼 하단에 표시하고 초점을 옮긴다. 입력 내용은 유지하며 재시도 시작 시 이전 오류를 지운다. 취소 후 새 폼에는 이전 오류를 전달하지 않는다. 저장 성공 후 목록 갱신 오류는 기존처럼 목록에 남긴다.
- 같은 사용자·작업의 중복 제출을 동기적으로 차단해 React의 비활성 상태 반영 전 연속 Enter에도 한 작업만 시작한다. 완료/실패 후 잠금은 해제한다. 입력은 계속 수정할 수 있고 기존 입력 식별 검사가 오래된 저장 결과·후속 쓰기를 차단한다.
- 일괄 주문은 모바일에서도 교재명 줄바꿈과 주문 수량 칸을 확보한다. 긴 오류는 하단 영역 안에서 스크롤되어 저장/취소를 밀어내지 않는다.

## 검증

관련 **203/203 검사 통과**. 9개 테스트 파일을 순차 실행했고 결과는 `.codex-artifacts/textbook-form-consistency-20260910/tests-accepted.log`에 기록했다. TypeScript, 최종 ESLint, production build와 diff 공백 검사도 통과했다.

- 요청: 같은 React 처리 내 2회 제출이 1회 RPC로 제한됨, 실패 후 교재명·수량·메모 유지, 오류 초점, 재시도, 취소 후 새 폼 오류 초기화.
- 출고: 저장 직전 재고 재조회 실패 시 선생님 선택 유지, 재시도 시 중복 조회 차단, 기존 학생 명단·중복 출고·음수 재고·입력 변경 보호 유지.
- 일괄 주문: 선택한 작업 상세 조회 실패 시 주문 수량 유지, 쓰기 미실행, 같은 대상 재시도 및 연속 제출 차단.
- 기존 필터·페이지·조회 모델·수량 계산·공통 표/행 작업 회귀 검증.
- TypeScript, 변경 파일 ESLint, production build, diff 공백 검사.

큰 renderer 파일에서 마지막 필터 시나리오 진입 시 테스트 프로세스가 두 번 `SIGKILL`로 종료됐다. 원인이 빌드 병렬 실행이라고 확정하지 않았다. 두 시나리오는 단독 실행에서 통과했다. 해당 Radix 필터 검사를 별도 테스트 파일로 분리하고 조작 도우미를 공통화해, 검사를 제외하지 않고 DOM 수명을 분리했다. 최종 결과는 분리 후 순차 실행을 기준으로 한다.

reduced-motion에서는 창·오버레이·진행 아이콘 애니메이션을 제거하는 클래스를 적용했다. OS 설정 전환 측정은 하지 않았다. 위 좌표는 정착된 상태의 실제 DOM 측정이며 전체 CLS나 운영 성능 측정은 아니다.

## 보존과 범위

변경 전후 소스를 비교해 기존 함수 193개와 저장 서비스 호출 25곳이 동일함을 확인했다(`preservation.json`). 변경 함수는 화면 구성, 피드백 초기화, 제출 전 보호에 한정된다. 수량·단가 계산, 저장 페이로드, 권한/인증, 최신 상세·재고 조회, 운영 DB·서비스 계약은 유지했다.

실제 운영 데이터 저장, 알림·문서 발송, DB 변경, 푸시·배포는 수행하지 않았다. 교재 재고의 마스터 등록 창과 별도 상세/문서 창은 이번 공통 폼 적용 범위에 포함하지 않았다.
