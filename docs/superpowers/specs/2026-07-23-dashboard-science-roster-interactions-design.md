# 대시보드 과학 통계·학생 명단 상호작용 설계

## 배경

현재 대시보드 과목 필터와 통계 버킷은 `전체`, `영어`, `수학`만 지원한다. 과학 과목 기반 데이터와 과학 시험 충돌 계산은 일부 준비되어 있지만, 과학 통계를 독립적으로 조회할 수 있는 필터와 집계 버킷은 빠져 있다.

학생 분포와 수업 운영은 개수만 보여 주고 실제 학생 명단을 확인하려면 다른 화면으로 이동해야 한다. 또한 수업 운영은 첫 그룹을 자동으로 펼치며, 학생 분포와 수업 운영의 바깥 Card 테두리가 내부 구분선과 겹쳐 화면이 복잡해 보인다.

## 목표

- 과학을 영어·수학과 같은 독립 대시보드 과목 필터로 제공한다.
- 학생 분포의 최하위 교차 행과 수업 운영의 개별 수업 행에서 학생 명단을 바로 확인한다.
- 수업 운영의 모든 그룹을 기본적으로 닫힌 상태로 시작한다.
- 학생 분포와 수업 운영의 불필요한 바깥 테두리만 제거한다.
- 기존 데이터 조회, 상단 필터, KPI, 내부 구분 구조는 유지한다.

## 비목표

- 새로운 DB 테이블, RPC 또는 별도 학생 조회 API를 추가하지 않는다.
- 학생 연락처, 상담 기록, 결제 정보 등 민감하거나 과도한 세부 정보는 표시하지 않는다.
- 과학 세부과목별 추가 필터를 이번 범위에 넣지 않는다.
- 대시보드 밖의 카드 또는 공통 `Card` 컴포넌트 스타일을 변경하지 않는다.

## 접근안 비교

### 1. Tooltip 또는 HoverCard

시각적으로 가장 가볍지만 hover가 없는 모바일에서 불안정하고, 긴 명단의 스크롤·키보드 조작·명시적 닫기 동작에 적합하지 않다.

### 2. 클릭형 Popover — 채택

현재 저장소의 Radix Popover를 재사용한다. 클릭·터치·키보드로 열 수 있고, 트리거에 붙어 나타나며 화면 가장자리 충돌을 자동으로 피한다. 명단이 길면 내부만 스크롤할 수 있다.

### 3. Dialog 또는 Sheet

긴 명단 처리에는 안정적이지만 대시보드 맥락을 과도하게 가리고, 단순 조회를 위해 화면 전환에 가까운 상호작용을 만든다.

## 데이터 계약

대시보드 집계 결과에 다음 학생 참조를 추가한다.

```ts
type DashboardStudentRef = {
  id: string
  name: string
  school: string
  grade: string
}
```

`BreakdownRow`와 `ClassSummaryRow`는 `studentRoster: DashboardStudentRef[]`를 가진다.

- 학생 ID 기준으로 중복을 제거한다.
- 이름 기준 한국어 오름차순으로 정렬한다.
- 학생 레코드가 없으면 ID는 내부 key로 유지하되 화면 이름은 `학생 정보 확인 필요`로 표시한다.
- 기존 `studentCount`는 고유 학생 수, `enrollmentCount`는 수강 건수 의미를 그대로 유지한다.
- 이미 대시보드에 전달되는 학생 데이터만 사용하며 추가 네트워크 요청을 만들지 않는다.

## 과학 통계

- `DashboardSubjectKey`에 `science`를 추가한다.
- 과목 탭에 `과학`을 추가한다.
- 통계 엔진의 과목 버킷에 `{ key: "science", label: "과학", subject: "과학" }`을 추가한다.
- UI의 과목 일치 함수가 `과학`과 `science`를 명시적으로 처리한다.
- `analyticsBySubject.science`와 `analyticsByView.science.{all,middle,high}`를 항상 생성한다.
- 과학 데이터가 없으면 기존 빈 상태와 0 지표를 사용한다.
- 고등부 우선 운영 정책은 실제 과학 수업 데이터와 저장 검증에서 유지하며, 대시보드 필터 자체는 일관성을 위해 모든 부서 조합에서 선택할 수 있다.

## 학생 명단 Popover

`section-cards.tsx` 내부에 공통 `StudentRosterPopover`를 둔다.

### 트리거

- 학생 분포의 상위 학년·학교 행은 기존 펼침/접힘 동작을 유지한다.
- 학년 아래 학교 행과 학교 아래 학년 행만 명단 Popover 트리거가 된다.
- 수업 운영의 그룹 헤더는 기존 펼침/접힘 동작을 유지한다.
- 펼쳐진 그룹 안의 개별 수업 행 전체가 명단 Popover 트리거가 된다.
- 트리거는 `button` 요소를 사용하고 `… 학생 명단 보기` 접근성 이름과 focus ring을 제공한다.

### 내용

- 헤더에는 현재 대상명과 총 학생 수를 표시한다.
- 각 행은 학생 이름을 주 정보로, 학교·학년을 작은 muted 보조 정보로 표시한다.
- 학교·학년이 없으면 빈 보조 문구를 억지로 만들지 않는다.
- 본문은 최대 높이를 두고 긴 명단만 내부 스크롤한다.
- 바깥 클릭과 `Esc`로 닫히며, 포커스는 트리거로 자연스럽게 돌아간다.
- 명단이 비어 있으면 `표시할 학생이 없습니다.`를 표시한다.
- 추가 카드, 중첩 배지, 장식용 구분선을 넣지 않는다.

## 기본 접힘

- 수업 운영의 `openGroupKeys`는 빈 `Set`으로 시작한다.
- 학년·선생님·강의실 모드를 바꿔도 첫 그룹을 자동으로 열지 않는다.
- 사용자가 명시적으로 누른 그룹만 열린다.
- 과목 또는 부서가 바뀌어 패널이 다시 생성될 때도 닫힌 상태로 시작한다.

## 테두리 단순화

- 학생 분포 Card와 수업 운영 Card에만 로컬 `border-0`을 적용한다.
- 상단 과목·부서 필터의 외곽선은 현재 범위를 한 묶음으로 보여 주므로 유지한다.
- KPI 외곽선과 셀 구분선은 빠른 수치 비교를 위해 유지한다.
- 학생 분포의 헤더, 두 열 구분, 행 구분선은 유지한다.
- 수업 운영의 내부 accordion 외곽, 그룹 행, 펼침 영역, 개별 수업 강조선은 유지한다.
- 공통 `Card` 컴포넌트와 다른 화면에는 영향을 주지 않는다.

## 반응형·접근성

- Popover 너비는 `min(18rem, calc(100vw - 2rem))` 범위로 제한한다.
- 본문은 `max-h-64`, `overflow-y-auto`, `overscroll-contain`을 사용한다.
- 마우스 hover 없이도 모든 기능을 사용할 수 있어야 한다.
- 트리거는 키보드 포커스와 `Enter`/`Space` 열기를 지원한다.
- 학생 명단은 읽기 전용이며 편집 동작을 포함하지 않는다.

## 오류와 빈 상태

- 과학 집계 데이터가 없어도 탭은 유지하고 기존 빈 상태를 보여 준다.
- 학생 레코드가 일부 누락되어도 전체 Popover를 숨기지 않고 해당 항목만 `학생 정보 확인 필요`로 표시한다.
- 연결 오류와 로딩 상태는 기존 대시보드 처리 방식을 그대로 사용한다.

## 테스트 전략

### RED

- 과학 과목 버킷과 과학 고등부 집계가 없어서 실패하는 메트릭 테스트를 추가한다.
- 학생 분포 최하위 행과 개별 수업 요약에 `studentRoster`가 없어서 실패하는 테스트를 추가한다.
- 과학 탭, Popover 계약, 기본 전체 접힘, Card 바깥 테두리 제거가 없어 실패하는 UI 소스 계약 테스트를 추가한다.

### GREEN

- 통계 데이터 계약을 최소 변경해 테스트를 통과시킨다.
- 공통 Popover와 트리거를 대시보드에 연결한다.
- 기본 자동 펼침 로직과 두 Card의 바깥 테두리만 변경한다.

### 검증

- `tests/dashboard-metrics.test.mjs`
- `tests/admin-shell.test.mjs`
- 관련 lint와 TypeScript/Next.js build
- `3000`의 production build를 재빌드·재시작한 뒤 `/admin/dashboard` 브라우저 QA

브라우저 QA는 과학 필터, 과학 지표, 모든 그룹 기본 접힘, 두 종류의 학생 명단 Popover, 바깥 클릭·`Esc` 닫기, 긴 목록 스크롤, 모바일 폭을 확인한다.

## 완료 기준

- 과학 탭을 누르면 영어·수학과 섞이지 않은 과학 통계가 표시된다.
- 학생 분포 최하위 행과 개별 수업 행을 누르면 이름·학교·학년 명단이 열린다.
- 수업 운영 그룹은 처음에 모두 닫혀 있다.
- 학생 분포와 수업 운영의 바깥 Card 테두리만 사라진다.
- 기존 영어·수학 통계, 학생·수강 집계 의미, 반응형 레이아웃에 회귀가 없다.
